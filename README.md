# FH3MP: Forza Horizon 3 online, back again

> **Early work in progress.** Expect crashes, desyncs and missing pieces.

Forza Horizon 3's online services barely work anymore. FH3MP brings them back for the Xbox One build of the game running on a PC through
[Azimuth](https://almost-there-games.itch.io/azimuth), with a replacement server run by the FH3MP team. No Microsoft or Xbox Live service
is contacted.

Seen working with real game clients so far:

- Online Free Roam
- Free Roam races
- Online Adventure
- Sharing and downloading designs, tunes and photos
- Rivals and Monthly Rivals
- Auction House

## Requirements

- A legitimately owned copy of Forza Horizon 3 (Xbox One build **1.0.125.0**)
- [Azimuth **1.0.4**](https://almost-there-games.itch.io/azimuth), set up so the game starts in it

No game files are in this repository or in the downloads.
